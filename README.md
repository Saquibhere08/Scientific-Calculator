# 🧮 Scientific Calculator with GUI and Graph Plotting

A Python-based scientific calculator using **Tkinter** for the GUI and **Matplotlib** for graph plotting. This tool supports basic arithmetic, trigonometric, logarithmic, exponential, and power functions. Easily plot common mathematical functions like `sin(x)`, `cos(x)`, `tan(x)`, `log(x)`, and more.

---

## 🚀 Features

- Basic arithmetic operations: `+`, `-`, `×`, `÷`
- Scientific functions: `sqrt`, `sin`, `cos`, `tan`, `log`, `ln`, `exp`, `power`
- Graph plotting for selected functions
- Clean and interactive GUI

---

## 🛠 Requirements

- Python 3.x
- Tkinter (comes pre-installed)
- Matplotlib
- NumPy

pip install matplotlib numpy
